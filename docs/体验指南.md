# PAI 体验指南 · 15 分钟走完核心闭环

> 这份指南以一位新用户的视角，带你完整体验这个原型的灵魂——**"AI 越用越懂你"**。
> 每一站都标了你会看到什么、点什么、以及背后发生了什么。全程用一个真实的学习场景贯穿：学「导数」。

---

## 第 0 站 · 启动与配置（约 1 分钟，仅第一次需要）

1. 终端运行 `npm run dev`，浏览器打开 **http://localhost:3000**。
2. 首次打开会看到顶部黄色提示「还差一步」→ 点击进入 **设置页**。
3. 三步完成配置：
   - ① **选服务商**：点一个按钮（智谱 GLM / DeepSeek / Kimi / OpenAI / 自定义），地址和推荐模型会自动填好；
   - ② **粘贴 API Key**：从对应平台官网获取（界面上有提示去哪申请）；
   - ③ **保存**。可先点「测试连接」——绿色「连接成功」或红色具体原因（Key 无效 / 余额不足 / 网络不通）。
4. **自查**：保存后顶部黄色提示条消失 = 配置成功。**保存即生效，不需要重启任何东西**。

> 配置存在本地数据库里，下次启动不用再配。改模型也在这里：换一个模型按钮 → 保存（Key 已记住，不用重输）。

---

## 第一站 · 问出第一个问题（画像为空的冷启动）

你会看到首页是空的，只有一句引导——这是设计好的空状态。

1. 点击 **「+ 开始新的学习」**，进入对话页。
2. 注意顶部：**没有**「依据 N 条画像知识点」的提示条。画像为空时它刻意隐藏，防止 AI"假装懂你"。
3. 在输入框问：**`什么是极限？`**，回车发送。

**你会看到：**
- AI 流式输出讲解，气泡上方有个紫色标签 **`L1 · 定义＋例子`**——这是默认档，因为 AI 对你一无所知。
- 讲解底部固定三排按钮：**再详细些 / 太啰嗦 / 换种讲法**，还有一个 **为什么这么讲**。
- 点开「为什么这么讲」：它会坦白告诉你"画像中无该概念的记录，使用默认 L1 档"——每一步都可解释，不装。

> 💡 刷新页面，消息还在——所有内容已持久化到本地 SQLite。

---

## 第二站 · 看看 AI 记住了你什么

1. 点顶部导航 **「画像」**。
2. **你会看到**：一个新条目「极限」，掌握度 **0.30**（红色条，首次提问的初始值），领域自动归类「高等数学/微积分」。
3. 点这一行展开：
   - **证据来源**：一条「对话第 1 条 ↗」，点它会跳回当时的提问并高亮——AI 的每条记忆都有出处，不是凭空捏造。
   - **变更历史**：`初始化 0.30`，信号类型「首次提问」。此后每次变化都会留痕。

> 这就是整个产品的差异化所在：**AI 对你的认知是透明的、可纠正的。**

---

## 第三站 · 体验"越用越懂你"（本产品的高光时刻）

回到对话页，接着问：**`什么是导数？`**

**你会看到：**
1. 回答的**开头 1–2 句**会先简短补一下"极限"（因为你画像里极限只有 0.30，还没掌握），然后才讲导数——这就是**前置依赖补齐**。
2. 气泡标签可能变为 **`L1 · 定义＋例子`**，但点开「为什么这么讲」，这次内容完全不同：
   - **判档依据**：画像命中 2 条知识点（导数 0.30 · 极限 0.30）
   - **先补基础**：极限（0.30）
   - **历史证据**：引用了你上一条消息的原话片段
3. 通知条会提示：`画像更新：新增画像：「导数」（0.30）；接触记录：「极限」`

**同一个人，同一个模型，第二次回答已经开始基于你是谁。**

---

## 第四站 · 反馈闭环：教会 AI 你的真实水平

假设刚才导数讲得**太啰嗦**了：

1. 点 **「太啰嗦」**。
2. **你会看到**：AI 立即重新生成，深度**下降一档**（更精炼），通知条显示 `「导数」掌握度 0.30 → 0.45`——因为它意识到之前**低估**了你。
3. 反过来，如果讲太浅，点「再详细些」会升一档并**下调**掌握度。
4. 点 **「历史版本」** 可以回看被替换的旧版回答——没有任何内容被销毁。

> 「再详细些 / 太啰嗦」不只是重答，它在**实时修正 AI 对你的画像**。去画像页刷新看看导数的掌握度吧。

---

## 第五站 · 亲手校准画像（你是最终真相）

AI 学错了？30 秒纠正它：

1. 画像页展开「导数」，点 **＋** 把掌握度步进到 **0.80**。
2. **你会看到**：条目出现绿色徽标 **「由你设定 · 剩 30 天」**——接下来 30 天，系统的自动推断**不会覆盖**你的判断（变更历史里也有 `user_edit` 记录）。
3. 之后再问导数相关问题，讲解直接按 L2 进阶档讲增量，不再重复基础。

> 场景演练：把「极限」手动调到 0.90，再回对话问一个微积分概念，「为什么这么讲」里的判档依据会立刻反映新数值。

---

## 第六站 · 编辑历史消息（问偏了就改，不用重来）

1. 回到对话页，把鼠标悬停在你早先的某条提问上，点 **「编辑」**。
2. 改成另一个问法（比如把"什么是导数"改成"导数的几何意义是什么"），点 **保存并重答**。
3. 弹窗问「是否让 AI 重新回答？」——点确认。
4. **你会看到**：
   - 那条消息标上「已编辑」；
   - 直接对应的 AI 回答被新版**替换**（旧版进历史版本）；
   - 更靠后的旧回答被折叠成灰色条「该回答基于修改前的提问内容」，可展开、也可单独重新生成——**旧内容永远可回看，绝不静默丢失**。

---

## 第七站 · 把学习带走：存为笔记

**两个入口**：① 对话页输入框下方的 **「📝 存为笔记」** 按钮（醒目的蓝框按钮）；② 首页会话列表，鼠标悬停任意会话，点 **📝 图标** 直接生成。

1. 点「存为笔记」后可先选**整理范围**：整个会话，或"从某条提问开始"（只整理后半段）——比如前半段聊跑偏了，就只整理有用的部分（生成约 10–30 秒）。
2. **你会看到**一篇固定六段结构的讲义：**一句话总结 / 核心概念 / 例子 / 常见误区 / 延伸问题**，数学公式（KaTeX）会渲染成真正的数学排版。
3. 四件事值得试：
   - 核心概念后面有 **¶N 小锚点**，点它 → 右侧滑出**对话原文**（不跳走页面），可一键「在对话中查看完整上下文」；
   - **划选正文任意术语** → 弹出即时解答浮层（1 秒内出现，按你的画像深浅作答）：**加入笔记**（进文末术语表，5 秒内可撤销）/ **深入讲解**（跳回对话预填问题）/ **换种说法** / **复制原文**；乱码会明确提示"未找到"，超过 200 字会建议转入对话总结；
   - 点右上 **「导出 Markdown」** → 下载 `讲义标题-日期.md`，锚点变成可点击的应用内链接；
   - 点 **「编辑」** 改讲义 → 保存后版本号 +1（v2、v3…），且**永远不会改写原对话**；若你在两个标签页同时编辑，会提示"检测到另一窗口的修改"，两个版本都保留，由你选择留哪个。

---

## 第八站（可选）· 优雅的删除

想清理练习数据？去首页删除一个会话，然后观察：

- 它生成的**笔记还在**，只是标上黄色「来源已删除」，正文完整可读可导出；
- 画像里仅来自该会话的**证据被移除**，证据清零的条目自动消失，其余不受影响。

**删除会留下痕迹说明，不会静默吞掉你学过的东西。**

## 收尾 · 设置页一览

顶部导航「设置」：
- **模型服务**：①选服务商（自动填地址）→ ②粘贴 API Key → ③选模型 → 保存即生效；可点「测试连接」即时验证，缺什么会明确提示；
- **单会话 Token 预算**：达到 80% 自动压缩上下文（画像精简、历史截短），超出 100% 拦截新调用并建议开新会话——成本护栏，防止长会话费用失控；
- **学习面板**：本周会话数、画像知识点数、笔记数、累计 tokens 与成本（配了单价才显示金额）；
- **数据管理**：一键导出全部数据（JSON）/ 彻底删除（需输入"删除"确认）。

## 常见问题

| 情况 | 说明 |
|---|---|
| 没配 Key | 页面可浏览，发送消息会收到明确提示（顶部黄色条 + 设置页有配置教程），不会白屏 |
| 生成中点「停止」 | 已生成内容保留并标「生成中断」，可一键重试 |
| 概念识别错了 | 画像页直接删除该条目，下次按"无记录"处理，不残留 |
| 概念归错领域 | 目前领域由抽取时判定，条目暂不支持改领域（原型限制） |
| 数据在哪 | 全部在本地 `data/pai.db`，随时导出/删除 |

**推荐体验路径回顾**：问极限 → 看画像 → 问导数（前置补齐）→ 点太啰嗦（反馈修正）→ 画像手动调 0.8（人工校准）→ 编辑旧提问（重答）→ 存为笔记（锚点+导出）。

这条路径正好是 PRD 的场景 A（概念学习闭环）→ 场景 C（画像校准）→ 沉淀带走，走完它，你就体验了这个产品想验证的全部核心假设。

# 笔记管理（N1–N5）· 新增能力速览

**组织检索**：笔记列表支持搜索（标题/正文/术语表）、按领域筛选（生成时自动归类，如"计算机科学"）、按时间排序。

**按概念归组**：列表页顶部切换「按概念归组」——同一概念的笔记自动聚在一组（AI 从内容识别关联概念）。

**追加整理**：又聊了已笔记化的主题？对话页「存为笔记」→ 切到「**合并进已有笔记**」→ 选目标笔记 → AI 把新内容融入旧笔记（去重、矛盾以新为准），版本 +1 可回退。锚点升级后，一篇笔记里的不同句子可以溯源到**不同会话**的原文。

**多篇合并**：笔记列表「选择合并」→ 勾选 2–6 篇 → 「合并为总纲」→ 生成一份新的总纲笔记（原文不动），溯源锚点保留，可跳回各自的原始对话。

**复习（推荐每周用）**：笔记列表右上「**开始复习**」→ 从「核心概念 + 术语表」自动生成问答卡 → 翻面自评「会了 / 还不会」→ **自评直接修正你的知识画像**（会 +0.1，不会 −0.15，被你手动锁定的知识点不受影响）。队列按"从未复习 → 最久未复习 → 最薄弱优先"排序。右上「Anki」可把卡片导出为 TSV 导入 Anki。

**自定义分类**：分类优先级是「你手动设置的 > AI 自动归类的」——
- **拖拽**：笔记列表里，把笔记卡片拖到任意领域标签上即可重新分类；
- **新建标签**：标签栏右侧「＋ 新建分类」可创建自定义标签（空标签也会保留在筛选栏），再把笔记拖进去；卡片悬停后点 🏷 也能单独设置分类；
- **笔记页内**：点元信息行的「🏷 分类名」徽标，选择现有分类或输入新分类名（自定义标签会自动出现在筛选栏）；
- 手动设置的分类会标注「· 手动」，自动归类永远不会覆盖它；想换分类，再拖一次或再编辑即可。

# 批次 F1 · 个人 AI 融合能力（Muse/Grok 启发）速览

**讲解语气可调**：对话页顶部「🎭 语气 ▾」随时切换（设置页也可改）——通用 / 苏格拉底式（先引导你自己推）/ 教练式（鼓励+小练习）/ 极简式（要点化）。切换即时生效，通知条会提示"下一条讲解生效"；用了非通用语气的回答，**消息头部带「🎭 教练式」徽标**——历史消息也能一眼看出当时用的是什么风格（"为什么这么讲"面板同样标注）。

**记忆回现**：有历史记录的概念，讲解开头会自然回现（"接着我们上次聊的 X…"）——学习是连续的，不是每次从零开始。

**苏格拉底引导模式**（🎭 选「苏格拉底式」后自动启用）：AI 不再一段话给答案，而是**分轮引导你**——先给探索方向 + 抛一个引导问题；你回答后它会反馈对错、递进下一步；几轮下来把知识讲清后，输出「🎓 学习复盘」（一起学到了什么 / 你的回答复盘 / 知识总结 / 遗留问题）。消息徽标会显示「引导中 / 已复盘」状态；复盘后新提问自动开启新一轮。

**今日学习建议**：首页的数据驱动洞察卡——复习到期、最薄弱概念、反复划选的术语、衰减预警，各带一键跳转。每天看一眼，按建议行动就是最高效的学习路径。

**完成通知**：存为笔记/追加整理期间切到别的标签页？完成后桌面通知提醒（首次会请求通知权限，拒绝则静默）。

# 批次 M2 · spec 驱动扩展速览

**可执行 Python 代码块**：对话与笔记里的 python 代码块带「▶ 运行」——数学概念直接画图（matplotlib 中文已支持）、编程学习即改即跑。首次运行需下载运行时（约 10–50MB，之后秒开）；30 秒无输出自动熔断。

**知识图谱**：首页洞察卡旁「🗺 知识图谱」——概念网络图，颜色=掌握度，连线=共现，点节点看证据与相关笔记，节点可拖拽。

**与笔记对话**：笔记页「问一问」——基于本篇笔记的问答面板，「存入笔记」把问答沉淀到延伸问题章节。

**学习周报**：笔记列表「学习周报」按钮——聚合本周数据生成叙事周报（保存为笔记，可导出）。
