# Dogfooding 体验指南 · 14 天成为 PAI 的第一位真实用户

> 这是给你的自用手册。PAI 的核心假设是「**画像让 AI 越用越懂你**」——这 14 天不是测试软件，是真实学习，顺便验证假设。每天投入 15–30 分钟即可，全程跟着首页「今日学习建议」走就是最优路径。
>
> 准备：设置页确认模型已配置；建议顺手选一个「讲解语气」（推荐先试**教练式**，第 8 天换**苏格拉底式**对比）。

---

## 第一周 · 让画像长出来（Day 1–7）

**目标**：画像 15+ 条概念、产出 5+ 篇笔记、走通一次完整闭环。

### 每日节奏（约 20 分钟）

1. **开场（1 分钟）**：打开首页，看「今日学习建议」——它今天推什么，就做什么。这是产品替你做的学习规划。
2. **学新概念（10–15 分钟）**：挑一门你正在学的课（比如线代、操作系统），问一个**真不懂**的概念。要点：
   - 不要客套提问，像平时问同学那样问（"特征值到底干嘛用的"比"请介绍特征值"好——前者会触发前置补齐，你会看到 AI 是否记得你的基础）；
   - 讲完不满意就点反馈按钮（太啰嗦/再详细些）——**你在亲手教 AI 认识你**；
   - 同一概念隔几天换角度再问，感受讲解是否明显不同于第一次（这是北极星假设的直接体验）。
3. **沉淀（3 分钟）**：满意就点「📝 存为笔记」。当天学的概念多篇相关时，试「合并进已有笔记」。
4. **每周 2–3 次复习**：点首页洞察卡的"该复习了"，或笔记页右上「开始复习」，翻卡片自评——**会/不会会直接改画像**，下次讲解立刻体现。

### 本周刻意体验清单（每项一次即可）

- [ ] Day 1：问第一个概念 → 画像页看到它出现（0.30）
- [ ] Day 2：同一概念追问 → 对话页顶部出现「依据 N 条画像知识点」；点开「为什么这么讲」看证据链
- [ ] Day 3：画像页手动把某概念调高到 0.8 → 再问相关问题，验证讲解直接进阶（不再重复基础）
- [ ] Day 4：编辑一条旧提问 → 观察旧回答折叠保留、新回答基于修改后内容
- [ ] Day 5：笔记页划词 → 「加入笔记」进术语表；划个乱码看它是否诚实说"未找到"
- [ ] Day 6：复习一轮卡片 → 画像页看掌握度变化记录
- [ ] Day 7：**第一次复盘**（见下）

### Day 7 复盘（10 分钟，写进笔记）

开一篇新笔记（或纸笔），回答三个问题：
1. 第二次问同一概念时，AI 明显更懂我了吗？举一个具体例子（截图对话页最好）。
2. 有没有哪次画像判错了（讲太浅/太深）？我纠错花了几秒？
3. 我自然想用它的场景是什么？哪些功能我根本没碰？

## 第二周 · 验证闭环与边界（Day 8–14）

**目标**：验证完整学习闭环（提问→讲解→笔记→复习→画像进化），探索边界。

### 继续日常，加上这些动作

1. **换人格对比（Day 8）**：设置页切到「苏格拉底式」学一天——哪种风格让你学得更快？这是只有你能回答的数据。
2. **跨会话连续性（Day 9–10）**：开新会话问老概念，体验"记忆回现"——"接着我们上次聊的 X"。连续性是 Muse 类产品的核心体验，PAI 的版本是透明可纠错的。
3. **笔记管理实战（Day 10–11）**：
   - 用搜索找旧笔记；拖拽重分类一次；
   - 同主题两篇笔记 → 「选择合并」生成总纲 → 检查溯源锚点还能跳回原对话。
4. **极限测试（Day 12–13，可选）**：
   - 故意聊超长会话，看 Token 预算 80% 压缩提示和 100% 拦截；
   - 划选 200+ 字段落转对话总结；
   - 两窗口同时编辑笔记看冲突保护。
5. **Day 14 总复盘**（20 分钟）——对照 PRD 2.3 指标：

| 指标 | 目标 | 你的估算方法 |
|---|---|---|
| 本周闭环次数 | ≥3 次/周 | 首页统计卡「本周闭环」直接读 |
| 概念命中率 | ≥60% | 对话页顶部画像提示条出现频率（大致感受即可，精确值等指标面板） |
| 讲解采纳率 | ≥80% | 点反馈按钮的频率——10 次讲解里点了 ≤2 次即达标 |
| 笔记产出率 | ≥30% | 有价值的会话里，存了笔记的比例 |
| 划词入库率 | ≥15% | 划词后点「加入笔记」的比例 |

### 决策日（Day 14 当天，回答一个问题）

**这两周 PAI 让我学得更快/更愿意学了吗？**
- **是** → 继续用，考虑推进：复盘指标面板（可视化上面那些数字）→ 触发条件满足则上 V0.6（可视化/PDF）；
- **不确定** → 看复盘笔记：是讲解质量问题（调 prompt/人格）还是工作流不合手（提需求，改起来快）；
- **否** → 诚实记录原因——这本身就是 dogfooding 最有价值的产出。

## 全程保持的习惯

1. **每天扫一眼洞察卡**——它是你的学习仪表盘；
2. **画像错了立刻改**——纠错成本 30 秒，这是产品最重要的信任机制；
3. **所有不舒服都说出来**（发给开发者=你自己）：记在 `docs/dogfooding-日志.md` 里，格式随意，一条也行。

## 数据安全提示

- 你的所有数据在本地 `data/pai.db`；设置页可一键导出 JSON 备份——**建议 Day 1 和 Day 14 各导出一次**；
- 误删了会话/笔记：没有回收站，但笔记有版本历史（编辑过的可回退）——重要内容先导出。
