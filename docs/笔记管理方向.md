# 笔记管理功能 · 方向梳理（供选型讨论）

> 基于当前已有的笔记能力盘点 + PRD 路线对齐，列出六个候选方向。每个方向标注：解决什么问题、与 PRD 的关系、工作量量级（S/M/L）、以及"现在做 vs 等规模"的建议。

## 现状盘点（已完成）

六段结构生成、溯源锚点（回对话原文）、术语表（去重/撤销）、Markdown 导出、二次编辑（版本历史 E-11）、删除与"来源已删除"状态、平铺列表页。**没有的**：搜索、标签/分类、排序筛选、复习机制、多篇整合、笔记间关联。

---

## 方向 A · 组织与检索（基础设施类）

**做什么**：全文搜索（SQLite FTS5，搜标题/正文/术语表）、自动标签（复用概念抽取的领域与概念名，零额外 LLM 成本）、手动标签、按领域/状态/时间筛选排序、收藏置顶。

**对应 PRD**：FR-01 的笔记页能力自然延伸；为 F4 复习提醒提供"选哪些笔记"的基础。

**价值判断**：笔记 <5 篇时感知弱，>15 篇时刚需。**建议现在做最小集**（搜索 + 自动领域归类 + 列表筛选），标签可等需要时再加。

**量级**：M（FTS5 建虚拟表 + 列表页改造，约一个批次的一半）

---

## 方向 B · 增量整理与多篇合并（解决碎片化，与画像强联动）

**做什么**：
1. **追加整理**：新对话聊了已笔记化的概念，一键把新内容合并进已有笔记（AI 做增量改写，版本 +1，旧版留档——复用 E-11 基础设施）；
2. **多篇合并**：勾选 2–3 篇同概念笔记 → AI 合成一份主题总纲（重复内容去重、错漏互补）；
3. **同概念归组**：画像里同一概念下的笔记自动关联（列表按概念分组展示）。

**对应 PRD**：直击"同一个概念聊了多次、笔记碎片化"的真实痛点；FR-08 信号（笔记生成刷新接触时间）天然需要"哪篇笔记对应哪个概念"的关系；为 F4 复习提供整合后的复习单元。

**价值判断**：**这是与产品灵魂（画像驱动）结合最紧的方向**——没有它，笔记会越攒越散，复习无从谈起。

**量级**：L（合并 prompt 设计 + 冲突处理 + 分组 UI）

---

## 方向 C · 复习机制轻量版（学习科学方向，F4 的前置）

**做什么**：
1. **复习视图**：从笔记的"核心概念"段自动抽取问答卡（概念名 → 定义），手动进入复习模式逐张自评（会 / 不会）；
2. **自评回流画像**："会" → 掌握度 +0.1（复用信号管道，上限 0.2 限制不变）、"不会" → -0.15 并把该笔记排入"待复习"；
3. **待复习队列**：按掌握度 × 距上次接触时间排序的简单队列（不做完整间隔重复算法，那是 F4 的活）。

**对应 PRD**：F4 主动助理（间隔复习提醒）的触发条件是"笔记存量 ≥20"且属 V1.0；本方向是**手动触发的轻量版**，不越 PRD 红线，但让北极星指标"7 日内复习"从 0 变 1——目前闭环的后半段（复习）完全没有数据产生。

**价值判断**：北极星指标是"提问→讲解→笔记→**7 日内复习**"，现在最后一环缺失。做完它，dogfooding 才能验证完整闭环。

**量级**：M（卡片抽取 + 复习页 + 信号复用）

---

## 方向 D · 笔记之上问答（RAG 雏形，V0.6 铺路）

**做什么**：在笔记页内提问，AI 基于这篇笔记（而非通用知识）回答；进阶为跨笔记检索（PRD §5.3 的 V0.6 向量检索路线——本期可先用关键词命中）。

**对应 PRD**：PRD 10.1 预留的 Source 素材实体的前置；向量检索引入（V0.6）的自然落地点。

**价值判断**：战略价值高但**当前规模收益低**（1–2 篇笔记直接贴全文进上下文就够，不需要检索）。建议排后，等笔记上量。

**量级**：M（单篇）/ L（跨笔记+检索）

---

## 方向 E · 导出生态

**做什么**：批量导出、Anki 卡片格式导出（配合方向 C）、单篇打印/PDF 排版。

**价值判断**：有真实需求（PRD 强调"知识能带走"）但实现简单、无差异化。可作为方向 C 的附属（卡片导出）顺手做。

**量级**：S

---

## 方向 F · 编辑器升级

**做什么**：富文本/分栏预览、图片插入、双向链接（[[wiki 链接]]）。

**对应 PRD**：双向链接与 Concept 关联图（PRD OP-01 遗留问题）同源；图片与 F3 可视化同源。

**价值判断**：工程量大（编辑器替换）且不解决当前任何痛点。**明确建议缓做**。

**量级**：L

---

## 推荐路线（供讨论）

**「B 的第 3 步（同概念归组）+ C（复习轻量版）」作为下一个批次**，理由：

1. 补上北极星指标的最后一环（复习），dogfooding 数据才算完整；
2. 同概念归组是 B 的地基，先做小件，追加/合并后续按需加；
3. 都复用现有基础设施（信号管道、版本历史、概念抽取），无新依赖；
4. 符合 PRD 节奏：F4 完整版仍等存量触发，轻量复习不越界。

**次选**：如果近期笔记量快速上涨，先做 A 的最小集（搜索+领域归类）。

**明确缓做**：D（等笔记上量）、E（顺手即可）、F（缓）。
