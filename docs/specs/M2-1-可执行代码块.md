# SPEC M2-1 · 可执行 Python 代码块

## 目标
对话与笔记中的 ```python 代码块从"只能看"升级为"能跑能改"：数学概念可视化（函数图像、矩阵变换）、编程学习即改即跑。

## 技术方案
- **运行时**：Pyodide（浏览器 WASM Python）v0.26.4，CDN 按需加载（首跑约 10–40MB，之后浏览器缓存）
- **隔离**：Web Worker 内执行，UI 不阻塞；无文件系统、无网络访问（纯沙箱）
- **计时两段分离**（2026-10-30 修复）：环境准备（运行时下载 + 包 install）与代码执行分开计——执行阶段 30s 熔断（死循环判定），环境准备阶段 180s 兜底（弱网不再被误判为死循环）；worker 在执行用户代码前发 `exec` 信号切换计时
- **预热**：代码卡片 mount 时静默 `pyodideRunner.warmup()`（幂等），下载运行时不等用户点运行
- **包白名单**：numpy / matplotlib（loadPackage）、sympy（micropip），按代码内容惰性加载，其余包不可用；matplotlib 装完立即 `matplotlib.use('AGG')`（plt.show() 只产生无害 warning）
- **中文字体**（2026-10-30）：代码含 CJK 时自动从同源 `/fonts/NotoSansSC-VF.ttf`（17MB，OFL 许可）装载并 `fontManager.addfont` 注册为首选字体（幂等缓存；失败降级为方框不阻断运行），并设 `axes.unicode_minus=False`；worker 上下文 fetch 不受页面 CSP/代理影响
- **图表**：执行后收集全部 figure → PNG base64 → 内嵌渲染

## API/协议
- Worker 消息：`init` / `run {id, code}` → `status {msg}` / `stdout {id, text}` / `exec`（环境准备完成，切换为执行计时）/ `result {id, ok, images?, error?}`
- 主线程 runner 单例（`src/lib/pyodide/runner.ts`）：管理 worker 生命周期、两段超时计时、消息分发
- Worker 文件：`public/pyodide-worker.js`（不打包，纯 JS）

## 交互
- 代码卡片：代码 + 「▶ 运行」；悬停出现「编辑」
- 编辑态：textarea 直接改代码 → 运行即用新代码；「还原」恢复原始代码
- 运行态：spinner + 状态文本（下载运行时/加载包/运行中）；输出区实时追加 stdout
- 结果区：stdout（等宽字体）+ 图表图片列表 + 错误（红色，显示 Python traceback 尾部）

## 验收标准
1. `print("hi")` → stdout 显示 hi
2. numpy 计算矩阵乘法 → 正确输出
3. matplotlib 画 sin 曲线 → 图表内嵌显示
4. 修改代码重跑 → 用新代码
5. `while True: pass` → 30s 超时提示，UI 不卡死
6. `import os; os.system("x")` → 不报安全错误但无系统副作用（WASM 沙箱）
7. 流式消息中途不触发运行；笔记页与对话页行为一致
