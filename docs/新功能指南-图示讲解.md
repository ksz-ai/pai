# 新功能指南 · 图示讲解（G 批次）

> 状态：**G1 已实现**（2026-10-30）。G2/G3 待迭代。
> 关联：`src/lib/diagram/`（DSL + 渲染器）、`src/lib/llm/prompts/explain.ts`（explain-v2）、`scripts/e2e-diagram.mjs`。

## 功能定位

对话讲解中的**图形解释**：问题涉及几何/空间关系时，AI 在讲解中自动生成图示并引用图中标注讲解（例：勾股定理 → 直角三角形 a=4、b=3、c=5 + 直角标记）。与 FR-03 自适应判档、导师人格叠加。

## 方案（已确认）

**结构化 DSL（JSON spec）+ 前端确定性渲染器**（方案 C）。关键分离：LLM 只在数学坐标系（x 右 / y 上）描述图元；翻转、缩放、取景、标签布局由代码保证——规避 LLM 直接画 SVG/SVG 坐标易错的问题。备选（LLM 直写 SVG、两段式生成）被否，理由见会话规划记录。

## 数据流

```
explain-v2 prompt（含 DSL 规范 + 勾股示例 + 使用判据）
  → LLM 输出 ```diagram JSON 围栏（嵌在讲解 Markdown 中，至多一个）
  → SSE delta 流式原样透传（未闭合围栏前端占位「📐 图示生成中…」）
  → 落库（INSERT/UPDATE messages.content）+ meta.has_diagram=true
  → Markdown.tsx pre 组件接管 language-diagram 围栏
  → validateDiagramSpec 校验：合法 → Diagram.tsx 渲染 SVG
                              非法 → 降级占位「📐 图示暂未渲染」，正文不受影响
  → 笔记生成：源文本 stripDiagramBlocks 剥离 spec（防 JSON 噪声进笔记）
```

## DSL v1 图元

| type | 字段 | 说明 |
|---|---|---|
| segment | from/to/label/dashed/arrow | 线段（箭头/虚线/标注） |
| polygon | points/fill/stroke | 多边形（默认浅蓝填充） |
| circle | center/r/dashed | 圆 |
| point | at/label | 点（青色实心） |
| angle | at/from/to/rightAngle | 角标（直角方块或弧线） |
| label | at/text | 自由文本 |

约束：元素 ≤ 16（prompt 要求 ≤ 15）、坐标有限数且 |v| ≤ 10⁴、字符串 ≤ 80、颜色仅 `#RGB/#RRGGBB/#RRGGBBAA/none` 白名单（进 SVG 属性，杜绝注入）。

渲染器：包围盒（含显式 axes 范围）+ 10% 边距 + 退化保护 → 统一缩放至 480px 宽 → `X/Y` 映射（Y 翻转）；线段标注自动放视觉上方一侧；X/Y 轴在原点可见时自动绘制。

## 人格与流程协调

- **苏格拉底引导轮（开启/续轮）禁图**——防剧透；复盘轮输出知识总结时可用
- minimal / coach 人格不受限；too_verbose / more_detail / rephrase 反馈重生成天然兼容

## 与 M2（python 代码卡片）的共存

`FENCE_LANGS = [diagram, python]` 共用流式保护（`hideStreamingFence`，按围栏语言给不同占位）；Markdown.tsx pre 接线分派 `language-python → PythonCodeBlock`、`language-diagram → Diagram`。笔记剥离只针对 diagram（python 代码是正向内容，保留）。

## 验证

`scripts/e2e-diagram.mjs`（17 项断言，mock-llm 场景：问"勾股定理"返回含图示讲解）：SSE 完整、流式围栏不吞、`meta.has_diagram`、`explain-v2`、spec 首关校验（JSON/类型白名单/坐标有限/颜色白名单）、围栏外正文不受影响、笔记无 spec 痕迹。浏览器侧（渲染效果/流式占位/非法降级）人工验证。

## 后续（未排期）

## token 成本说明

系统提示新增约 400 tokens（规范 + 示例 + 判据），每次讲解固定开销；预算压缩（FR-09）作用于历史注入与证据，不影响 system。输出端一个 diagram JSON ≈ 150–300 tokens。
