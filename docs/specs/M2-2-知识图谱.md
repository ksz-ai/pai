# SPEC M2-2 · 知识图谱可视化

## 目标
把已学概念画成交互式知识网络（PRD F3 首部分）：一眼看到"学了什么、它们怎么连、哪里薄弱"。

## 数据契约
`GET /api/graph` →
```json
{
  "nodes": [{ "id": "conceptId", "name": "特征值", "domain": "线性代数", "mastery": 0.3, "evidenceCount": 2, "noteCount": 1 }],
  "links": [{ "source": "idA", "target": "idB", "weight": 2 }]
}
```
- 节点：所有有画像条目或被笔记引用的概念
- 边：两概念出现在同一篇笔记（note_concepts 共现），weight = 共现次数

## 交互
- 力导向布局（引入 npm `force-graph`，canvas 渲染）；拖拽节点、滚轮缩放、双击聚焦
- 节点颜色 = 掌握度（红 <0.4 / 黄 0.4–0.7 / 绿 ≥0.7），节点大小 = 证据数
- 点节点 → 右侧栏：掌握度、证据跳转（对话第 N 条）、相关笔记列表
- 顶部领域筛选 chips（复用笔记页样式）

## 页面
`/graph`（顶导航不加，入口：首页统计区「知识图谱」链接 + 笔记页）
