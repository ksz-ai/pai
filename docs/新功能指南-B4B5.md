# 新功能使用指南 · 划词解答 与 成本护栏（B4 + B5）

> 本指南覆盖本轮新增的全部功能。按顺序走约 10 分钟，即可体验 PRD 批次 B4（划词解答 + 术语表）与 B5（Token 预算 + 异常兜底）的完整能力。
>
> 前置：设置页已配好模型服务（还没配的话，先按「第 0 站」三步完成）。

---

## 第 1 步 · 准备一篇笔记（如果你手头没有）

1. 首页 → **「+ 开始新的学习」** → 问一个概念（如 `什么是特征值`），可以追问一两轮让内容更丰富。
2. 点对话页底部 **「存为笔记」**，等待整理完成，自动跳转到笔记阅读页。

> 💡 建议问一个带数学的问题（比如"矩阵的特征值怎么求"），可以顺便看到公式渲染：`Av = λv` 会显示为真正的数学排版，矩阵会显示成带中括号的标准形式。

---

## 第 2 步 · 划词即时解答（核心新功能）

在笔记**阅读视图**里，用鼠标选中任意一个术语（比如"特征值"或"矩阵"）：

**你会看到：**
- 约 1 秒内，选中位置附近弹出**解答浮层**——先是"正在解答…"的加载态，随后解答流式打出来。
- 解答的长短深浅**取决于你的画像**：
  - 这个词你画像里掌握度低 → 讲得直白、带类比；
  - 掌握度高 → 直接讲进阶要点，不啰嗦定义。
- 浮层底部有四个操作按钮。

**四个按钮怎么用：**

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **加入笔记** | 把"术语 + 解释"写进笔记末尾自动创建的**术语表**章节 | 遇到值得记的术语，一键沉淀 |
| **深入讲解** | 跳回来源对话，输入框已预填"请深入讲解「X」"，回车即问 | 浮层里的小解释不够，想系统学 |
| **换种说法** | 同一深度换角度重答 | 第一种解释没讲到点上 |
| **复制原文** | 复制你选中的文本 | 想把原文粘贴到别处（划词不干扰正常复制） |

**两个边界情况（设计好的，不是 bug）：**
- 选中的是乱码/无意义字符串 → 浮层明确显示**"未找到相关解释"**，AI 不会硬编一个答案；
- 选中的超过 **200 字** → 不做解释，改为提示**"转入对话总结"**，点它会把这段带进对话让 AI 总结。

> 💡 划词只在笔记阅读页生效，正常选中文本复制、在其他页面操作完全不受影响。

## 第 3 步 · 术语表：加入、去重与撤销

1. 划选一个术语 → 解答出来后点 **「加入笔记」**：
   - 顶部出现绿色提示条 **"术语已加入术语表"，右侧有「撤销」按钮——5 秒内点它可完全恢复原状**；
   - 滚动到笔记末尾，能看到新增的 **`## 术语表`** 章节，条目格式为 `**术语**：解释`；
   - 笔记标题下方的元信息会显示"术语表 N 条"，导出 Markdown 时术语表一并带走。
2. **再次加入同一个术语** → 浮层内提示 **"该术语已在术语表中"**，给你两个选择：
   - **更新解释**：用这次的解答覆盖旧解释（适合你画像变了、解释深浅该跟着变）；
   - **跳过**：什么都不动，绝不产生重复条目。

> 典型用法：学习中期回头读旧笔记，划词解答会按你**当前**的水平给解释——比当初存的更贴合现在，这时点"更新解释"就是一次自然的笔记进化。

## 第 4 步 · 单会话 Token 预算（成本护栏）

到 **设置页 → 模型服务** 区块底部，有一项**「单会话 Token 预算」**（默认 60,000，可改），和"保存配置"一起生效。它的行为分两档：

| 会话累计用量 | 系统行为 | 你会看到 |
|---|---|---|
| 达到 **80%** | 自动压缩上下文：画像注入精简到 Top-3、舍弃历史证据原文、对话历史截短 | 对话页出现黄色通知条：*"会话已达 Token 预算 80%…已压缩上下文"*，回答照常继续 |
| 超出 **100%** | 拦截该会话的一切新调用（提问、反馈重答、生成笔记） | 明确提示：*"本次会话累计已用 N tokens，超出预算。建议开启新会话；当前会话内容仍可阅读与导出。"*，旁边有 **「开启新会话 →」** 一键按钮 |

**怎么理解这个设计：**
- 预算拦的是"这一个会话"而不是整个应用——所以永远不会出现"聊着聊着全站被锁"；
- 被拦的会话**只读不丢**：历史消息、已生成笔记全部保留可看可导出；
- 想继续学？点"开启新会话"即可，画像全量跟着你走，新会话照样懂你。

> 💡 日常使用不用管它；如果你发现某次长会话中途开始出现"压缩"提示，那是系统在替你控制成本，回答质量不受影响（画像判档依然生效）。

## 第 5 步 · 服务异常时的降级（你几乎感知不到，但值得知道）

模型服务出问题时，系统按固定顺序自救，**每一步都告诉你发生了什么**：

1. **自动重试一次**（约 1.2 秒后）——通知条："模型响应异常，正在重试…"；
2. 仍失败且你配了**备用模型** → 自动切换——通知条："主模型暂时不可用，已切换备用模型"（备用模型在设置页「高级选项」里填）；
3. 全部失败 → 明确的失败提示 + 已生成的部分内容保留并标注"未完成"，可点重试。

**体验原则：降级不等于"系统繁忙"。任何情况下你都知道发生了什么、还能做什么。**

## 第 6 步 · 多标签页同时编辑笔记（冲突保护）

场景：你开了两个标签页编辑同一篇笔记。

- 后保存的那个会收到提示：**"检测到另一窗口的修改，已保留两个版本"**；
- 弹窗让你选：**保留我的版本**（对方的版本自动存入历史）/ 取消（重新加载对方的最新版本）；
- 任何一次保存覆盖前，旧内容都会先存入版本历史（数据库 `note_versions`），**没有内容会被静默丢弃**。

> 这个场景平时碰不到，但碰到的那个瞬间你会感谢它。
