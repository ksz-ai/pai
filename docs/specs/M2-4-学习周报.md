# SPEC M2-4 · 学习周报

## 目标
每周一键生成一页叙事型学习周报：本周学了什么、掌握度怎么变、哪里薄弱、下周建议。可保存可导出。

## 数据聚合（全部现有表）
- 本周会话数 / 概念接触（messages.meta 提及去重）
- 掌握度变化：profile_logs 本周内 old→new 净变化 Top（升/降各 3）
- 笔记产出数、复习次数（review_logs）、划词次数
- 当前最薄弱 3 概念

## API
`POST /api/reports/weekly` → LLM 生成（prompt reports-weekly-v1：数据 JSON 注入 → Markdown 周报，结构：# 学习周报（日期区间）/ 本周概览 / 掌握度变化 / 薄弱点 / 下周建议）→ **以新笔记保存**（domain=学习周报，title=学习周报 MM-DD），返回 note

## 交互
笔记列表页头部「学习周报」按钮 → 生成（10–20s）→ 跳转周报笔记页。重复生成产生新版本内容（各自独立笔记，不做合并）。

## 验收
1. 生成成功 → 周报笔记存在且含四段结构
2. 数据段数字与实际一致（抽查会话数/复习次数）
3. 可导出 Markdown
