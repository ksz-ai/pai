# SPEC M2-3 · 与笔记对话

## 目标
在笔记阅读页直接向 AI 提问，回答基于**本篇笔记内容**与画像，可多轮追问；不切页面、不丢上下文。

## API
`POST /api/notes/[id]/ask`（SSE，body: `{question, history[]}`）→ 事件流 `meta/delta/done`（复用 explain 事件协议，meta.concept_name 为 null）
- system prompt（note-ask-v1）：你是笔记助手，基于下方笔记内容回答；笔记没覆盖的明确说"笔记里没讲到"，可用通用知识补充但标注；结合学习者画像深度
- 笔记全文注入（截断 8k 字符）；画像 Top-K 注入（复用 explain 的组装逻辑精简版）

## 交互
- 笔记页右滑对话面板（宽 420px）：消息流 + 输入框；多轮 history 客户端维护（上限 10 轮）
- 「存入笔记」：把本轮问答追加到笔记"延伸问题"章节（Q/A 格式，版本 +1，复用 writeContent）
- 面板为临时会话（刷新即失），不产生 conversations/记录（零成本问答）

## 验收
1. 问笔记里讲过的内容 → 回答基于笔记且带具体引用语气
2. 问笔记外内容 → 明确区分"笔记没讲到，但一般来说…"
3. 存入笔记 → 延伸问题区出现 Q/A，版本 +1
4. 未配置模型 → 明确报错
