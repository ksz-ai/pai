# SPEC M2-5 · 讲解质量深化（过程项）

## 目标
不加功能，专项打磨讲解质量——以真实对话为素材，系统性修订 explain prompt（v1 → v2）。

## 方法
1. 通读最近真实会话（API / 特征值 / 向量 / 递归），按五个维度挑毛病：
   - 结构（段落节奏、总长度、重点位置）
   - 例子质量（是否贴学习者语境、是否具体）
   - 易错点精准度（是否真的易错）
   - 公式呈现（KaTeX 渲染友好度：$$ 独立行、避免行内塞矩阵）
   - 深度档一致性（L1 是否真的"定义+例子"不越档）
2. 产出变更点清单 → 修订 `EXPLAIN_PROMPT_VERSION = "explain-v2"`
3. 真实模型同题 A/B（同问题 v1/v2 各一次）人工评审

## 验收
1. A/B 对比中 v2 在至少 2 个维度优于 v1（人工判定）
2. 深度档判档行为不变（AC-03 回归）
3. 苏格拉底/记忆回现/人格段不受破坏
