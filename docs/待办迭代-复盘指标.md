# 待办迭代 · 复盘指标可见化（已规划，暂缓实施）

> 状态：方案已设计，等确认后实施。触发时机建议：dogfooding 第 7 天临近时（复盘需要这些数字）。
> 关联文档：[迭代方向-个人AI思想融合.md](迭代方向-个人AI思想融合.md)（Muse/Grok 启发的六个增强方向）。

## 为什么是这件事

dogfooding 第 7/14 天复盘需要 PRD 2.3 的五项指标，V0.6（可视化/PDF）启动也由触发条件决定。逐项核对：闭环次数 ✓ 已可见；讲解采纳率、笔记产出率可算但无界面；概念命中率（覆盖率的有效替代口径）藏在 messages.meta；划词入库率缺数据（加入笔记动作从未记录）。

## 方案（设计完成，可直接执行）

1. **划词入库数据补全**：`POST /api/selection/track {note_id, term, action:'add'}` → selection_events；NoteReader 加入笔记成功后调用
2. **指标引擎** `GET /api/metrics`：7 日 + 全量两组，零新表
   - 概念命中率 = messages.meta.profile_hit 命中数 ÷ 总讲解数（覆盖率的有效替代口径，原口径在本架构下恒 100%）
   - 讲解采纳率 = 1 − profile_logs(feedback_*) ÷ ai_logs(explain)
   - 笔记产出率 = 有笔记会话 ÷ 总会话
   - 划词入库率 = selection_events(add) ÷ 划词总次数
   - 闭环完成次数 = 复用 week_closures
   - 附加：采纳率按周分桶（近 2 周，"稳定 2 周"判断）、导出次数近似（F5 触发）、各指标对照目标线达标布尔
3. **UI**：设置页学习面板新增「复盘指标」区块（数值 + 目标线 + 达标着色 + V0.6 触发状态行）
4. **对话页预算进度条**：会话头部细进度条（token_used ÷ 预算，80% 黄 / 100% 红）
5. **验证**：e2e 补指标数值断言 + 浏览器实测 + README/指南

## 明确不做（触发条件未满足）
F3 可视化、F4 主动助理（完整版推送）、F5 PDF 导入、向量检索、复习推送提醒——等指标数据说话。

> **2026-10-26 更新**：F4 的"主动"部分被 [迭代方向-个人AI思想融合.md](迭代方向-个人AI思想融合.md) 方向 2（数据驱动洞察卡，无推送）以轻量形式提前覆盖；向量检索之上可叠加融合方向 5（联网检索）作为互补——两者分别解决"基于你的记忆"与"基于最新世界知识"。
